# Cowork スケジュール設定ガイド

## 法務インテリジェンス収集スキルの自動実行設定

### 推奨スケジュール

**週次実行（月曜日 朝9:00）**

毎週月曜日の朝に前週分の法務情報を収集し、週の業務開始前にインプットを揃えます。

---

## Cowork での設定方法

### 1. 週次定期実行

Coworkのスケジュール機能で以下のプロンプトを登録してください。

**実行タイミング**: 毎週月曜日 09:00（JST）

**プロンプト**:
```
法務インテリジェンス 定期実行
```

このプロンプトにより、`legal-intelligence` スキルが自動起動し、
Phase 1〜5が順次実行されます。

---

### 2. 四半期サマリ（任意）

3ヶ月ごとに収集した情報を振り返り、重要度の高い動向をまとめます。

**実行タイミング**: 四半期末翌週月曜日（1月・4月・7月・10月の第1月曜日）

**プロンプト**:
```
法務インテリジェンス 四半期サマリ

直近3ヶ月の収集結果を振り返り、以下を生成してください：
1. ★★★案件のうち対応完了・対応中・未着手の整理
2. 来四半期の重要施行日・パブコメ締切カレンダー
3. マネーフォワード事業に影響が大きかった法改正TOP3
4. 次四半期に注目すべき法令・規制領域
```

---

## アドホック実行

スケジュール外で即時実行したい場合は、以下のいずれかのフレーズでClaudeに話しかけてください。

```
法務情報を今すぐ調べて
法務インテリジェンス 今週分を取得して
規制動向を調べて
パブコメを確認して
```

---

## 注意事項

- スキル実行にはClaudeのWeb検索機能が必要です。
- e-Govのフェッチに失敗した場合、代替検索クエリで自動補完します。
- 出力はClaudeの画面上にテキスト形式で表示されます。
  必要に応じてSlack等にコピー&ペーストしてご活用ください。

# 法務インテリジェンス収集スキル — 株式会社マネーフォワード

マネーフォワードの法務部門が、事業に影響する法規制動向を漏れなく把握するための
自動情報収集・構造化・出力システム。

## 実行モード

| モード | トリガー | 実行内容 |
|--------|----------|----------|
| **定期実行** | 「定期実行」またはCoworkスケジュール | Phase 1-5を順次実行 |
| **四半期サマリ** | 「四半期サマリ」 | 四半期サマリ生成 |
| **アドホック** | 「法務情報を今すぐ調べて」等 | Phase 1-5を即時実行 |

## Phase 2: 関連性フィルタリング

収集した情報をマネーフォワードとの関連度で3段階評価し、★以上のもののみ残す。

### 判定基準

**★★★ 直接影響**
- マネーフォワードの主要サービス（ME・クラウド会計・給与・勤怠・経費・請求書・ビジネス金融・X）の機能・運用に直接影響する法改正・規制
- 対応措置を講じる必要がある（約款改訂、機能改修、届出等）
- パブコメで意見提出を検討すべき案件（電子決済等代行・電帳法・個人情報・マイナンバー等）
- 施行日・対応期限が6ヶ月以内

**★★ 間接影響**
- フィンテック・SaaS業界一般に影響するが、マネーフォワード固有の対応は未確定
- マネーフォワードの顧客（中小企業・個人事業主・金融機関）の業務に影響し、サービス需要に波及しうる
- 審議会・WGの段階で、今後の法改正につながる可能性がある

**★ 要モニタリング**
- 中長期的にマネーフォワード事業に影響する可能性がある
- 業界全体のトレンドとして把握しておくべき（AI規制、海外データ保護動向等）

## Phase 3: 構造化・要約

フィルタリング通過した各項目を以下の形式で構造化する。

### 出力フィールド

| フィールド | 形式 | 備考 |
|------------|------|------|
| タイトル | 正式名称 or 端的な件名（30字以内） | |
| 要約 | 何が起きていて何が変わるか（80字以内） | |
| 対応期限 | パブコメ締切/施行日/意見提出期限 | 不明の場合は「未定」 |
| 関連度 | ★★★ 直接影響 / ★★ 間接影響 / ★ 要モニタリング | |
| カテゴリ | 法改正/パブコメ/審議会WG/ガイドライン/判例執行/業界ニュース | |
| 関連サービス | ME / クラウド会計 / クラウド給与 / クラウド勤怠 / クラウド経費 / クラウド請求書 / クラウド人事 / ビジネス金融 / X / 全社 | 複数可 |
| 関連法令 | 該当する法令名 | 複数可 |
| 収集日 | 実行日（YYYY-MM-DD） | |

### 本文テンプレート（各項目）

各項目について以下の構成で記載する:

```
## [タイトル]

**要約**: [何が起きていて何が変わるか、80字以内]
**関連度**: ★★★/★★/★　**カテゴリ**: [カテゴリ]　**対応期限**: [YYYY-MM-DD or 未定]
**関連サービス**: [サービス名]　**関連法令**: [法令名]

### 詳細
[背景と内容。200-400字]

### マネーフォワードへの影響
[なぜマネーフォワードに関係があるか。具体的にどのサービス・業務に影響するか。]

### 情報源
[元記事・官報・省庁ページへのリンク]

### 推奨アクション
[法務部門として取るべきアクション。なければ「現時点で具体的対応は不要。動向を注視。」]
```

## Phase 4: 出力（テキスト形式）

収集・構造化した情報をClaudeの画面上に以下の形式で出力する。

★★★の案件を最上部に配置し、★★、★の順で続ける。
同一関連度内では対応期限が近い順に並べる。

## 注意事項

- 検索クエリ内の年号は実行時に動的に解釈すること（「今年」「直近」等）。
- e-Gov直接フェッチが失敗した場合は代替クエリで補完し、その旨をレポートに記載。
- 同一案件の重複は1件にまとめ、情報源を複数併記する。
- 法令名・機関名は正式名称で記載する。

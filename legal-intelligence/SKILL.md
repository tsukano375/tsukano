# 法務インテリジェンス収集スキル（マネーフォワード版）

マネーフォワードの法務部門が、事業に影響する法規制動向を漏れなく把握するための
自動情報収集・構造化・出力システム。

> **⚠️ 注意（初回設定時）**
> このSKILL.mdは自動生成されたドラフトです。
> Phase 2（収集対象）・Phase 3（出力先・頻度）の設定は、Claude上で
> 「法務インテリジェンス設定を調整して」と入力して対話形式で変更できます。

## Phase 2: 関連性フィルタリング

収集した情報をマネーフォワードとの関連度で3段階評価し、★以上のもののみ残す。

### 判定基準

**★★★ 直接影響**
- マネーフォワードの主要サービス（ME、クラウド会計、クラウド給与、クラウド請求書、インボイス、MFX）の機能・運用に直接影響する法改正・規制
- 対応措置を講じる必要がある（利用規約改訂、機能改修、届出、ユーザー通知等）
- パブコメで意見提出を検討すべき案件
- 施行日・対応期限が6ヶ月以内

**★★ 間接影響**
- フィンテック・SaaS業界一般に影響するが、マネーフォワード固有の対応は未確定
- マネーフォワードの顧客（中小企業・個人事業主・金融機関）の業務に影響し、サービス需要に波及しうる
- 審議会・WGの段階で、今後の法改正につながる可能性がある

**★ 要モニタリング**
- 中長期的にマネーフォワードの事業に影響する可能性がある
- 業界全体のトレンドとして把握しておくべき
- 海外（ベトナム・EU）の規制動向で直接適用はまだ先

## Phase 3: 構造化・要約

フィルタリング通過した各項目を以下の形式で構造化する。

### 出力フィールド

| フィールド | 形式 | 備考 |
|------------|------|------|
| タイトル | 正式名称 or 端的な件名（30字以内） | |
| 要約 | 何が起きていて何が変わるか（80字以内） | |
| 対応期限 | パブコメ締切/施行日/意見提出期限 | 不明の場合は「未定」 |
| 関連度 | ★★★ 直接影響 / ★★ 間接影響 / ★ 要モニタリング | |
| カテゴリ | 法改正 / パブコメ / 審議会WG / ガイドライン / 判例執行 / 業界ニュース | |
| 関連サービス | ME / クラウド会計 / クラウド給与 / クラウド請求書 / インボイス / MFX / 全社 | 複数可 |
| 関連法令 | 該当する法令名 | 複数可 |
| 収集日 | 実行日（YYYY-MM-DD） | |
| 収集週 | YYYY-Wnn形式 | |

### 本文テンプレート（各項目）

```
【タイトル】
【要約】
【詳細】背景と内容（200〜400字）
【当社への影響】なぜマネーフォワードに関係があるか。具体的にどのサービス・業務に影響するか。
【情報源】元記事・官報・省庁ページへのリンク
【推奨アクション】法務部門として取るべきアクション。なければ「現時点で具体的対応は不要。動向を注視。」
```

## カスタマイズ方法

このスキルを調整したい場合は、Claudeに以下のように伝えてください。

- **法令を追加したい**: 「○○法を第1層に追加して。関連サービスは△△」
- **クエリを変更したい**: 「No.3の検索クエリを○○に変えて」
- **出力先をNotionに変えたい**: 「出力先をNotionに変更して。DBのURLは○○」
- **頻度を変えたい**: 「月次実行に変更して。毎月第1月曜日」

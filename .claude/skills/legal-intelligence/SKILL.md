# 法務インテリジェンス収集スキル — マネーフォワード株式会社

マネーフォワード法務部門が、フィンテック・SaaS事業に影響する法規制動向を
漏れなく把握するための自動情報収集・構造化・出力システム。

## 実行モード

| モード | トリガー | 実行内容 |
|--------|----------|----------|
| **定期実行** | 「定期実行」またはCoworkスケジュール | Phase 1-5を順次実行 |
| **四半期サマリ** | 「四半期サマリ」 | 過去3ヶ月の集計レポートを生成 |
| **アドホック** | 「法務情報を今すぐ調べて」等 | Phase 1-5を即時実行 |

## Phase 2: 関連性フィルタリング

収集した情報をマネーフォワードとの関連度で3段階評価し、★以上のもののみ残す。

### 判定基準

**★★★ 直接影響**
- ME・クラウド各サービス（会計/請求書/給与/勤怠/契約/経費）の機能・運用に直接影響する法改正・規制
- 資金移動業・貸金業・決済サービスに関する業法改正
- マイナンバー取扱・個人金融情報取扱に関わる具体的なガイドライン改訂
- 対応措置を講じる必要がある（約款改訂、機能改修、届出・登録等）
- パブコメで意見提出を検討すべき案件
- 施行日・対応期限が6ヶ月以内

**★★ 間接影響**
- フィンテック・SaaS業界一般に影響するが、当社固有の対応は未確定
- 当社の顧客（中小企業・個人）の業務に影響し、サービス需要・利用パターンに波及しうる
- 審議会・WGの段階で、今後の法改正につながる可能性がある
- 競合他社への影響が当社の市場ポジションに波及する案件

**★ 要モニタリング**
- 中長期的に当社事業に影響する可能性がある
- 業界全体のトレンドとして把握しておくべき
- 海外規制で国内展開前の動向把握として有用

## Phase 3: 構造化・要約

フィルタリング通過した各項目を以下の形式で構造化する。

### 出力フィールド

| フィールド | 形式 | 備考 |
|------------|------|------|
| タイトル | 正式名称 or 端的な件名（30字以内） | |
| 要約 | 何が起きていて何が変わるか（80字以内） | |
| 対応期限 | パブコメ締切/施行日/意見提出期限 | 不明の場合は空欄 |
| 関連度 | ★★★ 直接影響 / ★★ 間接影響 / ★ 要モニタリング | |
| カテゴリ | 法改正/パブコメ/審議会WG/ガイドライン/判例執行/業界ニュース | |
| 関連サービス | ME / クラウド会計 / クラウド請求書 / クラウド経費 / クラウド給与 / クラウド勤怠 / クラウド契約 / Pay for Business / ビジネスカード / クレジット / 全社 | 複数可 |
| 関連法令 | 該当する法令名 | 複数可 |
| 収集日 | 実行日（YYYY-MM-DD） | |
| 収集週 | YYYY-Wnn形式 | |

### 本文テンプレート

各項目について以下の構成で記載する:

1. **詳細**（背景と内容。200-400字）
2. **当社への影響**（なぜマネーフォワードに関係があるか。どのサービス・業務に影響するか）
3. **情報源**（元記事・官報・省庁ページへのリンク）
4. **推奨アクション**（法務部門として取るべきアクション。なければ「現時点で具体的対応は不要。動向を注視。」）

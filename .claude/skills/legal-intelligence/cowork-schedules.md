# Cowork スケジュール設定

法務インテリジェンス収集スキルの自動実行スケジュールです。

---

## 週次実行（推奨: 毎週月曜日）

Cowork のスケジュール機能で以下のプロンプトを設定してください。

### スケジュール設定

| 項目 | 設定値 |
|------|--------|
| 頻度 | 毎週月曜日 |
| 時刻 | 08:00 JST |
| プロンプト | 下記参照 |

### 週次実行プロンプト

```
法務インテリジェンス収集スキルの定期実行を開始してください。

今週分（直近7日間）の法務インテリジェンスを収集し、以下のフローで実行してください:
1. Phase 1: 23本の検索クエリを実行（第1層12本・第2層7本・パブコメ4本）+ e-Gov直接フェッチ
2. Phase 2: マネーフォワード事業コンテキストに基づき関連度フィルタリング（★〜★★★）
3. Phase 3: フィルタ通過項目を構造化・要約
4. Phase 4: 画面上に出力
5. Phase 5: 実行レポートを出力

完了後、★★★の項目とパブコメ締切2週間以内の案件を冒頭にサマリとして示してください。
```

---

## 四半期サマリ（3ヶ月ごと）

### スケジュール設定

| 項目 | 設定値 |
|------|--------|
| 頻度 | 四半期（1月・4月・7月・10月の第1月曜日） |
| 時刻 | 09:00 JST |
| プロンプト | 下記参照 |

### 四半期サマリプロンプト

```
法務インテリジェンスの四半期サマリを生成してください。

過去3ヶ月間の法規制動向について以下の観点でまとめてください:

1. ★★★（直接影響）案件の一覧と対応状況
2. 施行済み・施行予定の改正法令リスト
3. 継続注視が必要なパブコメ・審議会動向
4. 来四半期に注目すべき規制イベント（パブコメ締切、施行日等）
5. フィンテック・SaaS業界全体の規制トレンド総括

出力形式: 経営層・法務部門向けの要約形式（A4 2枚相当）
```

---

## 設定手順（Cowork）

1. Cowork を開く
2. **設定** → **スケジュール** → **新規作成**
3. 上記のスケジュール設定を入力
4. プロンプトを貼り付け
5. **保存して有効化**

---

## アドホック実行

スケジュール外で即時実行したい場合は、Cowork のチャットに以下を入力:

```
法務情報を今すぐ調べて
```

または:

```
法務インテリジェンス収集スキルを実行してください
```
